

# বাজার দর (BazarDor)

**A Bangla-language web application for exploring daily prices and price changes of essential products in Bangladesh.**

## About the Project

**বাজার দর (BazarDor)** helps users explore product prices through a clean, responsive interface in Bangla. The home page highlights products with rising and falling prices, while product and category pages make it easier to browse available items. Signed-in users can open protected product details to compare prices across markets.
Product and market-price information is supplied by the project's configured external API. Displayed prices depend on the data provided by that service.

## Technologies Used

- React 19
- JavaScript
- Tailwind CSS 3
- DaisyUI 4
- Better Auth
- MongoDB
- MongoDB Node.js Driver
- React Hot Toast
- Hind Siliguri
- External BazarDor API

## Key Features

1. Scrolling Price Ticker
2. Daily Price Increases and Decreases
3. Product Browsing, Category Filtering, and Price Sorting
4. Market-wise Price Comparison
5. User Authentication and Profile ManagementAccount and profile management** — Supports account registration and sign-in with email/password or configured Google and GitHub providers, plus profile viewing, name updates, and sign-out.
